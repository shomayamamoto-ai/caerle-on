# Caerle'on WordPress テーマ — 導入手順

現在の GitHub Pages のサイトを、そのままの見た目で WordPress へ移行するためのテーマです。
デザイン・レイアウト・動きはすべて同一で、**文章と写真を WordPress の管理画面から編集できる**ようになっています。

---

## 1. インストール

1. WordPress の管理画面にログイン
2. **外観 → テーマ → 新規追加 → テーマのアップロード**
3. `caerleon.zip` を選択して **今すぐインストール**
4. **有効化** をクリック

これだけでサイトの見た目が切り替わります。

### トップページの設定（重要）

WordPress の初期状態では「最新の投稿」がトップに出る場合があります。次を確認してください。

- **設定 → 表示設定 → ホームページの表示**
- 「固定ページ」を選び、ホームページに任意の固定ページ（例：「ホーム」）を指定

> ※ 固定ページを作っていない場合でも表示はされますが、上記の設定を行うのが確実です。

---

## 2. 文章・写真の編集

**外観 → カスタマイズ → Caerle'on サイト設定**

これまでの管理ページ（admin.html）に代わるものです。以下の項目をすべて編集できます。

| セクション | 編集できる内容 |
|---|---|
| トップ画面 | 背景写真、ロゴ、右上・右下の表記 |
| Concept | 写真、小見出し、キャッチコピー |
| Gallery | 小見出し、見出し、**写真 6 枚**（枠ごとに差し替え・削除） |
| System（料金） | 見出し、基本料金、**料金の項目**、サービス料・TAX |
| Access | 住所、営業時間、電話番号、**地図の埋め込み URL** |
| Recruit | 写真、見出し、本文、応募先の電話番号 |
| フッター | ロゴ、見出し、電話番号、営業時間、著作権表記 |
| SEO・共有設定 | ページタイトル、説明文、SNS 共有画像 |

編集したら右上の **「公開」** を押すと即座にサイトへ反映されます。

### 写真の差し替え

各項目の **「画像を選択」** をクリックし、メディアライブラリから選ぶか新しくアップロードします。
**削除**すると、その写真はサイトに表示されなくなります（ギャラリーは自動的に枚数が詰まります）。

### 料金の項目を増やす・減らす

「料金の項目」欄は **1 行に 1 項目**です。縦棒（`|`）で区切ります。

```
ホステスチャージ|1組様に付き|¥3,000
テーブルチャージ|1名様に付き|¥2,000
```

左から順に「名称 | 単位 | 金額」です。行を増やせば項目が増え、削除すれば減ります。

### 地図のピン位置

「Access → 地図の埋め込み URL」で変更できます。正確なピン位置にするには、

1. Google マップで店舗のページを開く
2. **共有 → 地図を埋め込む → HTML をコピー**
3. コピーした中の `src="..."` の **URL 部分だけ**を貼り付け

## 3. 移行にあたっての補足

### そのまま引き継がれるもの

- デザイン・レイアウト・配色・書体
- ギャラリーの横スライド（矢印・ドット・スワイプ）
- スマートフォン表示、ハンバーガーメニュー
- 構造化データ（JSON-LD）— 設定値から自動生成されるため、内容を変えると自動で追従します
- OGP / Twitter カードなどの共有設定

### 不要になるもの

- `admin.html`（カスタマイザーが役割を引き継ぎます）
- `admin-api.php`
- `content.json` / `photos.json`

WordPress にはログイン機能が標準で備わっているため、**独自のパスワード管理も不要**になります。

### 独自ドメインについて

WordPress を設置したサーバーでドメインを設定してください。
GitHub Pages のアドレスから移行する場合は、旧アドレスから新アドレスへの案内（リダイレクト）をご検討ください。

## 4. 収録ファイル

```
caerleon/
├── style.css          … テーマ情報とすべてのデザイン
├── functions.php      … テーマの基本設定・初期値・構造化データ
├── inc/customizer.php … 管理画面の編集項目
├── header.php         … ヘッダーとメニュー
├── front-page.php     … トップページ本体
├── footer.php         … フッター
├── index.php          … 予備のテンプレート
├── js/site.js         … スライド・メニューなどの動き
├── assets/img/        … 写真とロゴ（初期状態で使用）
└── screenshot.png     … テーマ一覧に表示される画像
```
