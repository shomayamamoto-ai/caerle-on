# WordPress 移行ガイド

Caerle'on のホームページを WordPress に移す手順です。
**専門知識は不要です。** 上から順にそのとおり進めれば完了します。

所要時間の目安：**1〜2時間**（サーバー契約の待ち時間を除く）

## ⚠️ はじめに必ずお読みください

**すでにお持ちの WordPress（他サイト用）には、このテーマを入れないでください。**

WordPress は **1 つにつき 1 サイト**という仕組みです。
別のサイトが動いている WordPress でこのテーマを**「有効化」すると、
そのサイトの見た目が Caerle'on のデザインに置き換わってしまいます。**

Caerle'on 用に、**新しく WordPress を用意する**のが正しい進め方です。
このガイドはその手順を案内しています。

> テーマを**アップロードするだけ**なら安全です（一覧に追加されるだけ）。
> 危険なのは**「有効化」を押すこと**です。

## STEP 0　はじめに用意するもの

手元に次の 2 つを準備してください。

| | |
|---|---|
| **`caerleon.zip`** | デザイン一式です。チャットでお渡ししたファイルをダウンロードしておいてください。**解凍せず、zip のまま**使います |
| **メールアドレス** | サーバー契約とログインに使います |

> **なぜ WordPress にすると費用がかかるの？**
> WordPress は「文章や写真をしまっておく倉庫（データベース）」を使う仕組みのため、
> それを動かせるサーバーが必要になります。月額 400〜1,000 円程度が目安です。

## STEP 1　サーバーを契約する

「レンタルサーバー」を契約します。以下のどれでも問題なく動きます。

| サービス | 月額の目安 | 特徴 |
|---|---|---|
| **ConoHa WING** | 約 900 円 | 契約と同時に WordPress を自動で用意してくれる。**最も迷いにくい** |
| エックスサーバー | 約 1,000 円 | 利用者が多く、困ったときに調べやすい |
| ロリポップ！（ハイスピード） | 約 550 円 | 費用を抑えたい場合 |
| さくらのレンタルサーバ | 約 500 円 | 老舗で安定 |

**初めての方には ConoHa WING をおすすめします。** 申し込みの途中で
「WordPress かんたんセットアップ」という項目が出てきて、**STEP 2 が自動で終わります。**

### 申し込み時に聞かれること

- **プラン** … 一番安いもので十分です
- **ドメイン** … サイトの住所（例：`caerleon-roppongi.com`）。多くのサーバーで **1 つ無料**でもらえます
- **WordPress かんたんセットアップ** … 「利用する」を選んでください

> ドメインをまだ決めていない場合でも、サーバー契約時にもらえる仮の住所
> （例：`〇〇.conohawing.com`）で先に進められます。あとから変更できます。

## STEP 2　WordPress をインストールする

> **STEP 1 で「WordPress かんたんセットアップ」を利用した方は、この STEP は不要です。**
> STEP 3 へ進んでください。

サーバーの管理画面にログインし、次のような名前のメニューを探します。

- 「**WordPress 簡単インストール**」
- 「**WordPress かんたんインストール**」
- 「**アプリケーションインストール**」

見つけたら、案内に従って進めます。入力するのは次の 4 つだけです。

| 項目 | 入力する内容 |
|---|---|
| サイトのタイトル | `六本木クラブ「カーリアン」` |
| ユーザー名 | ログインに使う名前（例：`caerleon-admin`） |
| パスワード | **推測されにくいもの**。必ずメモしてください |
| メールアドレス | ご自身のもの |

完了すると「管理画面はこちら」というリンクが表示されます。
**このリンクは必ずブックマークしてください。** 今後の編集はすべてここから行います。

> 管理画面の住所は `ご自身のサイトの住所/wp-admin` です。

---

## STEP 3　デザインを適用する

ここで Caerle'on のデザインになります。

1. 管理画面にログインします
2. 左側のメニューから **「外観」→「テーマ」** をクリック
3. 画面上部の **「新しいテーマを追加」** をクリック
4. さらに上部の **「テーマをアップロード」** をクリック
5. **「ファイルを選択」** から `caerleon.zip` を選ぶ
6. **「今すぐインストール」** をクリック
7. 完了画面が出たら **「有効化」** をクリック

> **「有効化」を押す前に、いま開いている管理画面が Caerle'on 用のものか確認してください。**
> 画面右上のサイト名、または左上のサイト名が Caerle'on 用のものになっていれば大丈夫です。
> 別のサイトの管理画面だった場合は、有効化せずに閉じてください。

**これで完了です。** サイトの住所を開くと、今のホームページと同じデザインが表示されます。

写真・文章・料金表もすべて入った状態で表示されますので、**移し替え作業は必要ありません。**

> **うまく表示されない場合**
> ブラウザに古い情報が残っていることがあります。
> `⌘ + Shift + R`（Mac）／ `Ctrl + F5`（Windows）で再読み込みしてください。

## STEP 4　最初にやっておく 3 つの設定

### ① サイトのタイトルを設定する

**「設定」→「一般」**

| 項目 | 入力する内容 |
|---|---|
| サイトのタイトル | `六本木クラブ「カーリアン」` |
| キャッチフレーズ | **空欄にしてください** |

入力したら、一番下の **「変更を保存」** をクリック。

### ② 検索エンジンに表示されるようにする

**「設定」→「表示設定」**

一番下に「検索エンジンでの表示」という項目があります。

> ☐ 検索エンジンがサイトをインデックスしないようにする

**このチェックは必ず外してください。** チェックが入っていると Google に表示されません。

### ③ アドレスの形式を整える

**「設定」→「パーマリンク」**

「投稿名」を選んで **「変更を保存」** をクリック。

## STEP 5　文章と写真を編集してみる

**「外観」→「カスタマイズ」→「Caerle'on サイト設定」**

ここが編集画面です。**42 の項目**を変更できます。

| 開く項目 | 変えられるもの |
|---|---|
| トップ画面 | 背景写真、ロゴ、右下の表記 |
| Concept | 写真、キャッチコピー |
| Gallery | 店内写真（6 枚） |
| System | 基本料金、料金の各項目、サービス料・TAX |
| Access | 住所、営業時間、電話番号、地図 |
| Recruit | 写真、募集文、応募先の電話番号 |
| フッター | 連絡先、著作権表記 |
| SEO・共有設定 | ページタイトル、説明文、キーワード |

### 操作のしかた

1. 左側で項目を選んで入力します
2. **右側にその場で反映されて見えます**（まだ公開されていません）
3. 気に入ったら右上の **「公開」** をクリック → サイトに反映されます

やり直したいときは「公開」を押さずに × で閉じれば、変更は破棄されます。

### 写真を差し替える

写真の項目にある **「画像を変更」** をクリック →
**「ファイルをアップロード」** から新しい写真を選ぶだけです。

**「削除」**を押すと、その写真はサイトに表示されなくなります
（ギャラリーは自動的に枚数が詰まります）。

### 料金の項目を増やす・減らす

「System」の中の「料金の項目」は、**1 行に 1 項目**です。
縦棒 `|` で区切って入力します。

```
ホステスチャージ|1組様に付き|¥3,000
テーブルチャージ|1名様に付き|¥2,000
```

左から順に「**名前 ｜ 単位 ｜ 金額**」です。
行を増やせば項目が増え、行を消せば項目が減ります。

### 地図のピンの位置を直す

「Access」の中の「地図の埋め込み URL」で変更できます。

1. Google マップで店舗のページを開く
2. **「共有」→「地図を埋め込む」→「HTML をコピー」**
3. コピーした文章の中から `src="` と `"` に挟まれた部分（`https://` で始まる長い文字列）だけを貼り付ける

## STEP 6　独自ドメインに切り替える

仮の住所で作った場合は、正式なドメインに切り替えます。

1. サーバーの管理画面で **「ドメイン設定」** を開く
2. 取得したドメインを追加する
3. **無料 SSL（https）を有効にする** ← 必ず行ってください
4. WordPress の **「設定」→「一般」** で
   「WordPress アドレス」「サイトアドレス」の両方を新しいドメインに変更

> **SSL とは？** サイトの住所が `https://` で始まるようにする設定です。
> 設定しないとブラウザに「保護されていない通信」と警告が出てしまいます。
> ほとんどのサーバーでボタン 1 つで無料設定できます。

### 今のホームページはどうする？

現在の `shomayamamoto-ai.github.io/caerle-on/` は、**そのまま残しておいて構いません**（無料です）。

新しいサイトが問題なく動いていることを 1〜2 週間確認してから、
名刺やSNSのリンクを新しいドメインに差し替えていくのが安全です。

## 困ったときは

### デザインが崩れている・真っ白になる

**「外観」→「テーマ」** で **Caerle'on** が「有効」になっているか確認してください。
別のテーマが有効になっている可能性があります。

### トップページに記事の一覧が出てしまう

このテーマはトップページ専用の作りになっているため、通常この症状は起きません。
もし起きた場合は **「外観」→「テーマ」** で Caerle'on が有効になっているかご確認ください。

### 変更したのにサイトに反映されない

- カスタマイザーで右上の **「公開」** を押し忘れていませんか
- ブラウザに古い情報が残っている可能性があります（`⌘+Shift+R` / `Ctrl+F5`）

### 写真をアップロードできない

写真のファイルサイズが大きすぎる可能性があります。
**5MB 以下**を目安にしてください。スマートフォンで撮った写真はそのままで大丈夫です。

### 文章を消したい／元に戻したい

入力欄を**空にして「公開」**すると、その文章はサイトに表示されなくなります
（見出しなどを消したいときに使えます）。

**元の文章に戻したい場合は、変更前の文章を入力し直してください。**
空欄にしても初期値には戻りません。

> 変更前の文章がわからなくなった場合は、下の「はじめの状態の文章」をご覧ください。

## 安全に使うために

- **WordPress の更新通知が出たら、なるべく早く更新してください**
  管理画面の上部に「更新してください」と表示されます。クリックするだけです
- ログインパスワードは推測されにくいものにしてください
- 「Wordfence Security」などの無料のセキュリティプラグインを入れておくとより安心です

---

## 移行後に不要になるもの

WordPress にはログイン機能と編集画面が最初から備わっているため、
これまで使っていた次のファイルは**不要**になります。

- `admin.html`（編集画面）
- `admin-api.php`
- `content.json` / `photos.json`

独自のパスワード管理も不要になります。
