写真の差し替え

各枠の「写真を選ぶ」から新しい写真を選択し、「保存」を押すとサイトに反映されます（反映まで 1〜2 分）。

接続設定

GitHub の Fine-grained personal access token（対象リポジトリ：shomayamamoto-ai/caerle-on、権限：Contents – Read and write）を入力してください。 トークンはこの端末のブラウザにのみ保存され、GitHub 以外へ送信されることはありません。 トークンを作成する ↗

・選んだ写真は自動で横 1920px・JPEG に最適化されてから保存されます。
・保存すると main ブランチに直接コミットされ、GitHub Pages が自動で再公開します。
・反映後に古い写真が表示される場合は、ブラウザを強制リロード（Mac: ⌘+Shift+R / Windows: Ctrl+F5）してください。
